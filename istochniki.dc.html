Источники данных рейтинга

Полный список независимых источников, реестров и стандартов, которые редакция использует при составлении и проверке рейтинга.

Отраслевые рейтинги

TAdviser Security 100
Ежегодный рейтинг крупнейших ИБ-компаний России по выручке от продажи и внедрения средств защиты информации. Методология: анкетирование участников и сверка с официальной финансовой отчётностью.
SecPost — таблица игроков рынка ИБ
Публикует расширенный список из 140+ компаний со специализацией и клиентской базой. Методология: данные ФНС и опрос участников рынка.

Государственные реестры и регуляторы

ФСТЭК России
Федеральная служба по техническому и экспортному контролю — открытый реестр лицензий на техническую защиту конфиденциальной информации и реестр сертифицированных средств защиты.
Реестр отечественного ПО (Минцифры)
Единый реестр российских программ для ЭВМ — проверка присутствия продукта для задач импортозамещения.
152-ФЗ «О персональных данных», 187-ФЗ «О безопасности КИИ»
Базовые нормативные акты, на соответствие которым проверяются заявленные компетенции интеграторов и аудиторов.

Отраслевые стандарты

ГОСТ Р 57580
Стандарт Банка России по защите информации финансовых организаций — упоминается при оценке компаний с фокусом на финсектор.
ISO/IEC 27001
Международный стандарт систем менеджмента информационной безопасности.
OWASP
Open Worldwide Application Security Project — используется как справочная база при оценке методологии пентеста веб-приложений.
